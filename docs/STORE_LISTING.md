# Play Store listing (draft)

**App name** (≤30): `Nasc – SSH Client`

**Short description** (≤80):
`Fast, private SSH terminal with saved hosts, secure keys and command autocomplete.`

**Full description** (≤4000):

Nasc is a clean, fast SSH client for Android.

CONNECT
• Save hosts and open multiple sessions in tabs; they stay connected in the background
• Full terminal with 256 colours, scrollback, resize and copy/paste
• Extra key row: Esc, Tab, arrows, | ~ / - and a sticky Ctrl

KEYS, DONE SAFELY
• Generate Ed25519 or RSA keys on your phone, or import your own
• Private keys are encrypted and protected by the Android Keystore – they never leave the device
• Optional App lock: require your fingerprint, face or screen lock to open Nasc
• Trust-on-first-use host verification with a clear warning if a server's key changes

WORK FASTER
• Autocomplete from your own command history, per host – tap a suggestion or press Tab
• Anything typed at a password prompt is never recorded

PRIVATE BY DESIGN
• No account, no ads, no analytics, no tracking
• Connects only to the servers you choose

Nasc needs an SSH server to connect to (a Linux box, Raspberry Pi, VPS, NAS, etc.).
